# 01_语言规范校对 · 需求规格说明书 v2.0

> 第一波次交付物（2026-08-23）· 基于基线能力清单（03 号文档）+ 顶尖标准对标表（02 号文档）
> 版本 v2.0（2026-08-23 · 基于波次 2 方案更新）：需求完整、标准明确、可落地；已升级 v2.0

## 1. 项目定位

独立可调用的**专业语言规范校对工具**：三级校对（基础/语法/语义）+ 分领域文体适配 + 修订痕迹与校对报告 + MCP 插件化嵌入 PAEG 生态（简历/法律文书等工具输出流程）。

## 2. 需求清单（校验用，每条可验收）

### REQ-A 三级校对体系

| ID | 需求 | 验收标准 | 优先级 |
|---|---|---|---|
| A1 | 基础级：错别字/标点/格式错误识别与修正 | 规则库 ≥50 条；修正可定位 | P0 |
| A2 | 语法级：搭配不当/句式杂糅/语序不当/成分残缺 | 继承基线 L-03/L-04/L-06 全部能力 | P0 |
| A3 | 语义级：逻辑矛盾/概念混淆/歧义/用词不当，不改变原意 | 原意保持率 ≥95%（测试集） | P0 |
| A4 | 三级可独立开关、可分级报告 | 配置开关生效 | P1 |

### REQ-B 分领域适配

| ID | 需求 | 验收标准 | 优先级 |
|---|---|---|---|
| B1 | 文体预设：学术论文/公文/简历/法律文书/通用 | ≥5 文体 | P0 |
| B2 | 专业术语保护：术语白名单不误改 | 术语误改率 0 | P0 |
| B3 | 文体规则包可配置扩展 | 新增文体不改核心 | P1 |

### REQ-C 可追溯输出

| ID | 需求 | 验收标准 | 优先级 |
|---|---|---|---|
| C1 | 修订痕迹：位置/原文/改文/理由/类型 | 每条修改可定位可解释 | P0 |
| C2 | 校对报告：问题类型统计 + 修改建议 | 报告结构化输出 | P0 |
| C3 | diff 视图（网页端修订痕迹视图） | 波次 3 网页端验收 | P1 |

### REQ-D 插件化与生态

| ID | 需求 | 验收标准 | 优先级 |
|---|---|---|---|
| D1 | MCP Server：tools/resources/prompts 三原语 | tools/list 动态发现 | P0 |
| D2 | 可嵌入简历/法律文书输出流程（PAEG 调度） | 多工具串联演示 | P0 |
| D3 | 统一错误码/强类型参数/JSON Schema | 契约测试通过 | P0 |
| D4 | 网页端：粘贴/上传→校对→修订视图→报告→导出 | 全链路可跑通 | P1 |

### REQ-E 基线保留（能力不退化）

| ID | 需求 | 验收标准 | 优先级 |
|---|---|---|---|
| E1 | 基线 L-01~L-12 全部保留（见 03 号文档） | 反向审计 100% | P0 |
| E2 | 薇依语料/禁词表/AI_TELLS 原样保留 | 文件与词条数一致 | P0 |

## 3. 非功能需求

| 项 | 要求 |
|---|---|
| 性能 | 基础级 ≥1 万字/分钟；语法/语义级异步可配 |
| 安全 | 无状态服务；会话上下文由 Host 管理；API 密钥不入库 |
| 兼容 | Python 3.10+；独立可运行（不依赖 PAEG 主项目） |
| 可移植 | 基线 chat_fn 注入机制保留，LLM 可替换 |

## 5. 范围边界（v1.0 不含）

- 不做专业排版引擎（校对输出接外部排版）
- 不做语音校对
- 多语种校对（当前中文为主，接口预留）
