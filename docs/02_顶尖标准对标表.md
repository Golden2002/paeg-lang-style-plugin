# 01_语言规范校对 · 顶尖标准对标表

> 第一波次·顶尖标准对齐交付物（2026-08-23）
> 对标对象：黑马校对（黑马校对软件）、版慎通（方正）、蜜度文修 V4.0（专业校对/版面检查）
> 调研来源：[蜜度文修 V4.0 校对能力跃升](https://www.cbbr.com.cn/contents/500/105388.html)、[蜜度文修 V4.0 持续提升专业校对能力](https://m.it168.com/article_6906334.html)

## 一、行业顶尖标准（对标基准）

| 维度 | 行业顶尖能力（黑马/版慎通/蜜度文修） | 量化指标 |
|---|---|---|
| 校对层级 | 错别字/标点/格式 → 语法/搭配/语序 → 语义/逻辑/歧义 三级体系 | 三级可分级开关 |
| 领域适配 | 学术论文/公文/新闻/图书/简历/法律文书文体规范 | ≥6 文体预设 |
| 专业术语保护 | 术语库白名单，不误改专业词汇 | 术语误改率 0 |
| 修改可追溯 | 修订痕迹视图 + 修改理由 + 校对报告（问题类型/修改建议） | 每条修改有定位+理由 |
| 语义级校对 | 逻辑矛盾/概念混淆/歧义/用词不当，不改变原意 | 原意保持率 ≥95% |
| 批量与性能 | 万字级文本秒级校对 | ≥1 万字/分钟 |
| 插件化 | 独立工具可嵌入出版/办公流程 | 标准 API 可集成 |

## 二、基线现状（PAEG 语言规范模块 L-01~L-12）

| 维度 | 基线能力 | 现状评级 |
|---|---|---|
| 校对层级 | L-02/L-03 AI 味检测 + Self-Refine；L-04 省略句/动宾/介词；L-06 病句规则 | 🟡 仅"AI 味/语法级"两层，无基础级（错别字/标点/格式）与语义级（逻辑/歧义） |
| 领域适配 | 无（薇依风格为通用对话/教学风格） | 🔴 无文体预设 |
| 专业术语保护 | L-10 外部禁词白名单（反方向：禁 AI 腔） | 🟡 有词表机制但无"术语保护"语义 |
| 修改可追溯 | 无（只返回修正后文本） | 🔴 无修订痕迹/报告 |
| 语义级校对 | L-05 高频词重复检测（部分语义） | 🟡 仅词汇层面 |
| 批量与性能 | L-07/L-08 规则快路径 + LLM 慢路径 | 🟢 规则层秒级 |
| 插件化 | 主项目内模块（lang_gate 统一入口） | 🔴 非独立 MCP Server |

## 三、差距清单与实现指标（波次 3 开发目标）

| 编号 | 顶尖能力 | 基线现状 | 差距 | 实现指标（验收） |
|---|---|---|---|---|
| P-01 | 三级校对体系 | 无基础级/语义级 | 新增基础级（错别字/标点/格式规则库）+ 语义级（逻辑矛盾/歧义检测） | 三级可独立开关；基础级规则 ≥50 条；语义级基于 LLM+规则双通道 |
| P-02 | 分领域适配 | 无 | 文体预设：学术/公文/简历/法律文书/通用 | ≥5 文体；每文体有专属规则包（术语表+格式规范） |
| P-03 | 术语保护 | 词表机制 | 术语白名单 + 校对时跳过/提示不误改 | 术语误改率 0（测试断言） |
| P-04 | 修订痕迹/校对报告 | 无 | diff 结构（位置+原文+改文+理由+类型）+ 报告视图 | 每条修改可定位可解释；报告含问题类型统计 |
| P-05 | 原意保持 | LLM refine 可能扩写 | 语义级改写约束 + 原意保持校验（相似度阈值） | 原意保持率 ≥95%（测试样本集） |
| P-06 | MCP 插件化 | 主项目内模块 | 独立 MCP Server（tools/resources/prompts 三原语） | tools/list 发现校对工具；可被 PAEG 主 Agent 调度 |
| P-07 | 网页端 | 无 | 校对交互界面（粘贴/上传→校对→修订视图→报告） | 全链路可跑通 |
| P-08 | 性能 | 规则层快 | LLM 路径异步化 | 基础级 ≥1 万字/分钟；语法级可配置异步 |
