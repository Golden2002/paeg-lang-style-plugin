## 模块职责

| 模块 | 职责 | 用户需求对应 |
|---|---|---|
| `prompts/language_style.py` | 词法/句法规则系统提示词（约束 LLM） | ⭐ 系统提示词约束 |
| `forbidden.py` | 动态违禁词库（运行时增删 + JSON 热加载） | ⭐ 动态违禁词库 |
| `refiner.py` | 重写 LLM 输出（多轮 Self-Refine） | ⭐ 重写工具 |
| `rules.py` | 词法/句法规则数据 + 检测（正则） | 规则引擎 |
| `ai_taste.py` | AI 味检测（5 维信号） | 检测前置 |
| `gate.py` | L0+L2 守门编排 | 统一入口 |

## 数据流（gate_content 全链路）

```
输入文本
  │
  ▼ L0-0 病句确定性修正（fix_known_gaffes，纯规则）
  │       "我在这里听着你。" → "我就在这里听你说说。"
  ▼ L0 基础修正（polish_fn，注入式；缺省跳过）
  ▼ L2 深度矫正（refiner.refine，注入式）
  │       detect_ai_taste（ai_likelihood ≥ 0.45 触发）
  │       → LLM 按 language_style 提示词重写（chat_fn 注入）
  │       → 复检 < 0.4 停止；最多 max_rounds 轮
  ▼ 收口 病句规则再跑一遍（改写可能重新引入悬空'听着你'）
  ▼
规范输出
```

## 依赖设计（插件化关键）

| 特性 | 实现 |
|---|---|
| **零宿主依赖** | 不 import PAEG 任何模块（services/infra/subagents/prompts） |
| **LLM 注入式** | `make_refiner(chat_fn=...)` 强制注入；None 抛 TypeError（fail-fast） |
| **守门注入式** | `gate_content(refiner=None)` 纯规则；注入 refiner 启用 L2 |
| **配置外置** | 违禁词/语料在 `data/*.json`，可热加载 |
| **行为一致性** | test_parity.py：20 段样本 vs PAEG 原实现字符串相等 |

## 与三大架构模式对应（librarian 调研）

| 模式 | 范式 | 插件实现 |
|---|---|---|
| 规则声明式引擎 | LanguageTool（grammar.xml） | `rules.py` 正则规则集 |
| 公式度量 | textstat（语言公式） | `ai_taste.py` 统计信号 |
| 中文特化 | jieba+LTP（分词/依存） | `rules.py` 正则分句（零依赖轻量版；如需高精度可升级 LTP） |
