## 二、能力清单（L 编号，100% 覆盖）

| 编号 | 能力名称 | 能力描述 | 模块/文件位置 | 验证方式 |
|---|---|---|---|---|
| L-01 | AI 腔词检测 | 577 项 AI 腔模式（"总的来说/赋能/点亮/让我们"等）子串检测，返回命中列表 | language_refiner.py `AI_TELLS` / `detect_ai_tells` | 单测断言命中 |
| L-02 | AI 味多维信号检测 | 句长变异度 burstiness、过渡词密度 marker_density、三点列举数、破折号数、段落对称度，综合 ai_likelihood | ai_taste_detector.py `detect_ai_taste` / `AITasteSignals` | 单测（test_chain_integration 触发） |
| L-03 | Self-Refine 多轮语言矫正 | 薇依语料 few-shot + 反馈生成 + LLM 改写 + 复检循环（max_rounds=2），去除 AI 痕迹 | language_refiner.py `LanguageRefiner.refine` | 真实 LLM 调用验证 |
| L-04 | 省略句/无主句检测 | 句首动词（先看/记住/注意）、无主语短语（不催你/先不急）、动宾搭配不当（带着重量）、悬空宾语、介词规范、复合句缺主语 | language_refiner.py `_check_ellipsis` | 单测断言触发反馈 |
| L-05 | 高频词重复检测 | 200 字窗口内"重量/真实/看见/感受"等核心词 ≥3 次触发同义词轮换建议 | language_refiner.py `_check_word_repetition` | 单测 |
| L-06 | 病句确定性修正 | fix_known_gaffes：悬空"听着你"类病句（缺补语）正则修正，句末/停顿锚定只修病句、保护合法搭配 | language_refiner.py `fix_known_gaffes` / `_GAFFE_FIX_RULES` | test_round19_gaffe_fix 9/9 |
| L-07 | 统一语言守门入口 | lang_gate_content：L0-0 病句前置 + L0 polish + L2 深度矫正 + 最终收口不变量；lang_gate_short 快路径 | services/lang_gate.py `lang_gate_content` / `lang_gate_short` | 链路测试 |
| L-08 | 全局守门兼容入口 | polish_text：AI 味/省略句/动宾触发条件 → refine，任一层异常静默回退原文 | services/polish.py `polish_text` | 测试（test_contracts） |
| L-09 | 薇依语料 few-shot | weil_corpus.json 真实语料（前 6 条进 system prompt），风格锚定 | weil_corpus.json + `_build_system` | 结构校验 |
| L-10 | 外部禁词可配置 | data/forbidden_words.json 三类禁词合并进 AI_TELLS，无需改代码 | data/forbidden_words.json + `_load_extra_forbidden` | 文件存在 + 合并断言 |
| L-11 | 静默降级安全 | 所有矫正链路 try/except 包裹，异常回退原文，不阻塞生成 | 全部入口函数 | 异常注入测试 |
| L-12 | 可移植注入接口 | chat_fn 注入式（缺省 subagents._safe_chat），LLM 调用可解耦替换 | language_refiner.py `__init__(chat_fn)` | 构造测试 |

## 三、能力缺口（相对顶尖标准，供波次 3 升级）

1. 无**三级校对体系**（当前是"AI 味矫正"，非"错别字/语法/语义"分级）
2. 无**修订痕迹/校对报告**输出（当前只返回修正后文本）
3. 无**分领域适配**（学术/公文/简历/法律文书文体规范）
4. 无 **MCP 标准件**（主项目内以模块存在，非独立 MCP Server）
5. 无**网页端**（校对交互界面）

> 缺口项将在《顶尖标准对标表》中展开，作为波次 3 开发目标；基线能力 L-01~L-12 必须 100% 保留。
