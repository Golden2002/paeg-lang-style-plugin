# 产物 2：语法检查 `check_ellipsis`（8 类规则）

## 能力说明
按标点切句后逐句检查：词法完整 / 动宾搭配 / 悬空宾语 / 无主语短语 / 复合句缺主语 / 介词规范 / 谓宾补足 / 语义残缺。返回问题列表（每条含修正建议）。

## 实测输入 / 输出

| 类别 | 输入 | 命中问题 |
|---|---|---|
| 词法-道出 | 他道出了真相。 | ⚠ 『道出』压缩写法 → 『说出来』 |
| 动宾搭配 | 这句话带着重量。 | ⚠ 『带着重量』动宾不通 → 『这句话的分量很重』 |
| 悬空宾语 | 我想与你探讨。 | ⚠ 『与你探讨』缺宾语 → 『与你探讨这个问题』 |
| 无主语 | 不催你，你慢慢来。 | ⚠ 缺主语 → 『老师不催你，你慢慢来』 |
| 复合句缺主语 | 因为学习了，进步了。 | ⚠ 分句缺主语 → 『因为学习了，所以我进步了』 |
| 语义残缺 | 这是最直觉的地方。 | ⚠ 『最直觉的』→ 『最直观的』 |
| 干净文本 | 这道题的思路很清楚，我们一起算一遍。 | （无问题） |

## 结果判定
✅ **良好**（8 类中 7 类实测命中；「谓宾补足/听着你」由 `fix_known_gaffes` 承担，属分工）。

## 发现与修复
- **未修复（保留 parity）**：`"关于学习方面。"` 这类「介词短语独立成句」在 `check_ellipsis` 中漏检——分句切分用 `。` 作分隔符，句末标点被剥离后 `BAD_PREPOSITIONS` 要求的字面 `[，。；]` 不再满足。`check_syntax_general_rule`（通则层）可命中该情形。为保持与 PAEG 基线行为一致（`test_parity.py`）未改动。
- **未修复（分工）**：`"你有点倦。"` 的"倦"不在 `check_ellipsis` 的列举规则内（其规则是"觉得倦了/感到倦/已倦"），由通则层 `check_lexicon_general_rule` 检测。
