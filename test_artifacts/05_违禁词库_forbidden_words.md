# 产物 5：动态违禁词库 `ForbiddenWords`

## 能力说明
内置违禁词库（AI 腔套话 / 空洞大词 / 伪共情 / 廉价鼓励 / 网络用语 / 空洞赞美形容词）+ 外部 JSON 三类合并（extra_forbidden / pseudo_empathy_verbs / ai_tells_extra）+ 运行时增删。

## 实测输入 / 输出

| 操作 | 结果 |
|---|---|
| `detect("总的来说，让我们一起加油，赋能未来！")` | `['总的来说', '让我们', '让我们一起', '赋能', '加油']` |
| `detect_count(同上)` | 5 |
| `add("自定义禁词")` → `detect("含 自定义禁词")` | True → `['自定义禁词']` |
| `remove("自定义禁词")` | True |
| `load_json(显式路径)` | added=11 |
| `load_json()`（默认路径） | added=11（包内 data 生效） |
| 内置词数 | 552 |

## 结果判定
✅ **顶尖水平**。552 内置词、三类外部 JSON 正确合并（含伪共情类"被听见"），动态增删与默认路径加载均正常。

## 发现与修复
无缺陷（`load_json` 已读三键，与审计文档 L-10 一致）。
