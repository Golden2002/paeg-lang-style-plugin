# 产物 13：测试样本集（真实中文文本）

> 本文件汇总各产物实测用到的真实中文样本，作为回归样本与"顶尖水平"人工复核基准。

## 病句 / 语法样本

| 样本 | 目标能力 | 期望 |
|---|---|---|
| 我在这里听着你。 | 病句修正 | 我就在这里听你说说。 |
| 老师在这里听着你，你慢慢说。 | 病句修正 | 老师在这里听你说说，你慢慢说。 |
| 我在这里听着你说，别急。 | 合法搭配保护 | 原样不变 |
| 他道出了真相。 | 词法完整 | 提示"道出→说出来" |
| 这句话带着重量。 | 动宾搭配 | 提示"带着重量→有很重的分量" |
| 我想与你探讨。 | 悬空宾语 | 提示"与你探讨→与你探讨这个问题" |
| 不催你，你慢慢来。 | 无主语 | 提示补主语 |
| 因为学习了，进步了。 | 复合句缺主语 | 提示补主语 |
| 关于学习方面。 | 介词（通则层） | check_syntax_general_rule 命中 |
| 这是最直觉的地方。 | 语义残缺 | 提示"最直觉的→最直观的" |
| 你有点倦。 | 单字状态词（通则） | check_lexicon_general_rule 命中 |
| 他工作很辛苦，别去麻烦别人。 | 复合词不误报 | 通则返回空 |

## 校对报告样本（proofread）

```
他写了一个帐号，感到好象有点倦。这个结论绝对正确！！我在这里听着你。  他说："大概也许可行。"
```
→ 修正后：`他写了一个账号，感到好像有点倦。这个结论基本正确！我就在这里听你说说。他说："大概可行。"`

## LLM 重写样本

```
总的来说，让我们一起赋能这个时代，点亮无限可能！
```
→（DeepSeek）`这个时代不需要我们点燃什么。它已经在燃烧。我们所做的每一件诚实的事，都只是往火里添一根柴。`
