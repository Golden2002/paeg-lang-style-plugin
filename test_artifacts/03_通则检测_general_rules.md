# 产物 3：通则检测（词法完整 / 句法完整 / 充分状语）

## 能力说明
"通则"层指挥 LLM 泛化（非逐词修补）：`check_lexicon_general_rule`（单字状态词）、`check_syntax_general_rule`（句子成分齐全）、`check_adverbial_general_rule`（状语充分）。

## 发现与修复
- **F2（已修复）**：裸子串 `if single in text` 把"辛苦/麻烦/困难/混乱"误判为单字状态词。改为**复合词掩码法**（剔除完整词形与 `_SAFE_COMPOUNDS` 后再判单字是否独立）。
- **F3（已修复）**：规则集里 `rule-lx-general-001` 的裸字符类 pattern 同样误报，改为 `pattern=None`（prompt-only），单字检测统一走本通则。

## 结果判定
✅ **顶尖水平（修复后）**。真单字状态词零漏报、常见复合词零误报。
